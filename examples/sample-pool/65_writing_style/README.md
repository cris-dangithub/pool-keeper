# Writing style — Maren Okafor

How this person writes in their own "formal" register. Any skill that writes on the person's behalf (CV, cover letter, LinkedIn, emails) **must** use it, so the result does not sound like generic AI prose.

## How to use (for writing skills)
1. Read the active rules file **before** writing. Follow every rule with status `active` whose scope matches the document type and language.
2. Priority when rules clash:
   1. rules from corrections (`Origin: K###`) — strongest, they come straight from the person
   2. rules with a higher Strength
   3. rules from document patterns (`Origin: pattern [S###]`)
   4. examples in the observed patterns file
3. Use the observed patterns for example sentences, vocabulary and structure; never copy habits marked "do not imitate".
4. Ignore rules with status `replaced by G###`.
5. Facts (numbers, titles, dates) **always** come from the other pool files, never from the examples here.

## How the person corrects
After another skill produced a text, the person can paste it together with the version they expected. The correction is logged (K###) and the active rules are updated automatically.
