# Style correction log (K###)

Every time the person pastes a text produced by an AI/skill together with the version they expected, the correction is logged here (newest first) and the active rules are updated. Format:

```
## K### — <YYYY-MM-DD> — <document type / originating skill / offer>
### AI text (literal)
> ...
### Expected text (literal)
> ...
### Difference analysis
- ...
### Rules
- New: G### — ...
- Strengthened: G### (Strength n → n+1)
- Replaced: G### → G###
```
